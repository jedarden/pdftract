## Why This Cannot Be Completed Automatedly

This bead is **deliberately OPS-GATED** because it requires:

1. **Cloudflare account access** — to create the Pages project and configure DNS
2. **OpenBao access** — to verify/create the API token secret
3. **Domain ownership** — pdftract.com is a production domain, DNS changes require maintainer approval

These are infrastructure operations that cannot be performed via git/CI. They require:
- Cloudflare dashboard/API credentials
- OpenBao admin access
- Production DNS change approval

## Architectural Context

Per ADR-010 (docs/plan/plan.md ~line 567), this work is part of making pdftract visible ahead of the full registry release cascade:

> "Getting the full 10-registry release cascade to actually run is tracked separately and is a long pole; it should not have to gate a visitor being able to experience pdftract's actual differentiator — correct multi-column reading order and font-encoding recovery on documents that break other extractors — today, with nothing installed."

The decision to go live NOW vs. waiting for v1.0.0 is a **maintainer decision** about:
- Visibility timeline
- Documentation completeness
- Support burden for a pre-v1.0.0 project
