## Architecture notes

- **Deployment flow:** pdftract-docs-build workflow → builds mdBook → `wrangler pages deploy` → Cloudflare Pages (`pdftract-com` project)
- **DNS flow:** pdftract.com (CNAME) → pdftract-com.pages.dev → Cloudflare Pages CDN → mdBook content
- **Secrets flow:** OpenBao (`rs-manager/iad-ci/cloudflare/pages`) → ESO → `cloudflare-pages-secret` K8s Secret → workflow env var
- **Idempotency:** Re-running workflow against same tag overwrites deployment cleanly
