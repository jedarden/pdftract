## CRITICAL BLOCKER: Binary Portability Issue 🔴

### Problem
The `target/release/pdftract` binary was compiled on NixOS and has hardcoded NixOS library paths. When executed in the current environment, it fails to load shared libraries:

```
Error: Failed to extract PDF
Error: Failed to compute fingerprint from file
```

**Root Cause**: NixOS store paths in binary:
```
/nix/store/5m9amsvvh2z8sl7jrnc87hzy21glw6k1-glibc-2.40-66/lib/libgcc_s.so.1
/nix/store/y4d9amsvvh2z8sl7jrnc87hzy21glw6k1-glibc-2.40-66/etc/ld.so.cache
```

### Impact
- All conformance tests fail at the binary level, NOT the SDK level
- SDK code is correctly implemented and ready
- Build infrastructure is correctly configured
- Only the Rust binary has portability issues

### Workarounds Attempted
1. ✅ Rebuilt binary locally: Succeeded, but binary still fails
2. ❌ Rebuild with all features: Fails due to missing leptonica (lept) dependency
3. ⚠️ Basic rebuild: Produces same failing binary
