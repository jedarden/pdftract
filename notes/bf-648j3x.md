# Verification Note: bf-648j3x - Streaming Support and Ergonomics Layer

## Summary

Implemented the streaming support (Readable) and ergonomics layer for the pdftract-node SDK.

## Implementation Completed

### 1. Streaming Layer (`src/stream.ts`)
- **`NdjsonReadable` class**: Extends Node.js `Readable` stream
  - Consumes stdout line-by-line from subprocess
  - Splits on `\n` and handles partial lines (buffer preservation)
  - Emits parsed JSON objects (Page for extractStream, Match for search)
  - Implements backpressure via `_read()` method
  - Handles subprocess errors and exit codes via `StreamError`
  - Proper cleanup via `_destroy()` method

- **`createExtractStream()`**: Factory function for extract operations
  - Returns `NdjsonReadable` configured for Page objects
  - Supports timeout, env, and highWaterMark options

- **`createSearchStream()`**: Factory function for search operations
  - Returns `NdjsonReadable` configured for Match objects
  - Supports timeout, env, and highWaterMark options

### 2. Ergonomics Layer (`src/ergonomics.ts`)
- **`normalizeOptions(options: object): string[]`**
  - Converts camelCase options to kebab-case CLI flags
  - Handles ExtractOptions, SearchOptions, BaseOptions
  - Validates option types and ranges before converting

- **`coerceSource(source: string | URL | Buffer): any`**
  - Handles URL objects (preserves URL instance)
  - Handles Buffers (for BytesSource)
  - Handles strings (paths and URLs)
  - Returns already-normalized Source objects as-is

- **`validateOptions(options: object): void`**
  - Validates numeric ranges (ocrThreshold: 0-100, minImageSize: >=0, etc.)
  - Validates string options (non-empty ocrLanguage, valid imageFormat values)
  - Throws descriptive TypeErrors for invalid values

- **Helper functions**:
  - `isUrl(str: string): boolean` - Type guard for URL detection
  - `isBuffer(value: unknown): boolean` - Type guard for Buffer detection
  - `mergeOptions<T>(defaults, overrides): T` - Combine option objects
  - `lazyOptions<T>(factory): T` - Lazy option evaluation

### 3. Integration with Generated Methods (`src/codegen/methods.ts`)
The generated Client class methods use both layers:
- `extractStreamReadable()`: Uses `createExtractStream()` with normalized options
- `searchReadable()`: Uses `createSearchStream()` with normalized options
- All methods: Use `normalizeOptions()` and `validateOptions()` for option handling
