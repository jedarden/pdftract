### Implementation Details

**Key Components:**

1. **`pdftract_binary_path()`** (lines 15-17): Uses `CARGO_BIN_EXE_pdftract` env var to locate binary
2. **`PdftractCommand` builder** (lines 139-278): Fluent API for constructing invocations
   - `new()` - creates command with binary existence check
   - `arg()`, `args()` - add arguments
   - `stdin()`, `stdout()`, `stderr()` - configure stdio
   - `spawn()` - spawn process and return handle
   - `output()` - run and capture output automatically
   - `with_file()` - convenience for PDF file processing
   - `mcp_stdio()` - convenience for MCP server spawning

3. **`CapturedOutput` struct** (lines 69-136): Holds stdout/stderr bytes and exit code
   - Provides convenience methods: `success()`, `stdout_str()`, `stderr_str()`, `combined_output()`

4. **`verify_binary_available()`** (lines 289-298): Validates binary exists
