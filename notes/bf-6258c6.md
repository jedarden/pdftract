# Empty Document Variants Catalog

## Overview

This document catalogs all possible ways a PDF Document can be empty or minimally structured, as identified through code analysis of `pdftract-core/src/document.rs`, `parser/catalog.rs`, and `parser/pages.rs`. Each variant includes detection location, error type, and example scenarios.

## Detection Entry Point

All empty document detection flows through `validate_pages_structure()` in `document.rs:734-883`, which is called by `Document::open()` and `Document::open_remote()` immediately after parsing the catalog.

---

## Variant 1: Null/Zero Pages Reference

**Location:** `document.rs:742`
**Error Type:** `DocumentError::MissingPagesArray`
**Detection Code:**
```rust
if catalog.pages_ref.object == 0 {
    return Err(DocumentError::MissingPagesArray { source });
}
```

**Scenario:** The catalog's `/Pages` field is either:
- Missing entirely (emits `STRUCT_MISSING_KEY` during catalog parsing)
- Explicitly set to an invalid reference (object ID = 0)

**Example PDF Structure:**
```pdf
%PDF-1.4
1 0 obj
<<
/Type /Catalog
/Pages 0 0 R        % Explicit zero reference
>>
endobj
...
```

**Alternative (Missing /Pages):**
```pdf
1 0 obj
<<
/Type /Catalog
% No /Pages entry
>>
endobj
```

**Behavior:** Catalog parsing returns a default Catalog with `pages_ref = ObjRef::new(0, 0)` and emits `STRUCT_MISSING_KEY` diagnostic.

## Variant 2: Unresolvable Pages Reference

**Location:** `document.rs:749-756`
**Error Type:** `DocumentError::MissingPagesArray`
**Detection Code:**
```rust
let pages_obj = match resolver.resolve(catalog.pages_ref) {
    Ok(obj) => obj,
    Err(_) => {
        return Err(DocumentError::MissingPagesArray { source });
    }
};
```

**Scenario:** The catalog references a `/Pages` object that doesn't exist in the xref table.

**Example PDF Structure:**
```pdf
%PDF-1.4
1 0 obj
<<
/Type /Catalog
/Pages 999 0 R    % Object 999 doesn't exist
>>
endobj
xref
0 2
0000000000 65535 f
0000000009 00000 n
trailer
<<
/Size 2
/Root 1 0 R
>>
startxref
100
%%EOF
```

**Behavior:** `resolver.resolve()` returns `Err` because object ID 999 is not in the xref table.

## Variant 3: Non-Dictionary Pages Node

**Location:** `document.rs:760-767`
**Error Type:** `DocumentError::MissingPagesArray`
**Detection Code:**
```rust
let pages_dict = match pages_obj.as_dict() {
    Some(dict) => dict,
    None => {
        return Err(DocumentError::MissingPagesArray { source });
    }
};
```

**Scenario:** The `/Pages` reference resolves to an object that is not a dictionary (e.g., an integer, string, array, or stream).

**Example PDF Structures:**

**Integer:**
```pdf
2 0 obj
42            % /Pages resolves to an integer
endobj
```

**String:**
```pdf
2 0 obj
(Not a dict)  % /Pages resolves to a string
endobj
```

**Array (malformed):**
```pdf
2 0 obj
[1 2 3]       % /Pages should be a dict, not an array
endobj
```

**Behavior:** The Pages node must be a dictionary per PDF spec. Direct objects are invalid.

## Variant 4: Wrong /Type on Pages Node

**Location:** `document.rs:774-801`
**Error Type:** `DocumentError::EmptyDocument`
**Detection Code:**
```rust
if let Some(type_obj) = pages_dict.get("Type") {
    match type_obj {
        PdfObject::Name(type_name) => {
            if type_name.as_ref() != "Pages" {
                return Err(DocumentError::EmptyDocument { source });
            }
        }
        _ => {
            return Err(DocumentError::EmptyDocument { source });
        }
    }
}
```

**Scenario:** The Pages dictionary has a `/Type` entry that is not "Pages".

**Example PDF Structures:**

**Wrong Type Name:**
```pdf
2 0 obj
<<
/Type /Page          % Should be /Pages (plural)
/Kids [3 0 R]
/Count 1
>>
endobj
```

**Non-Name /Type:**
```pdf
2 0 obj
<<
/Type (Pages)        % /Type should be a name, not a string
/Kids [3 0 R]
>>
endobj
```

**Behavior:** Root Pages node must have `/Type /Pages`. A leaf /Page node appearing as the root is structural error.

## Variant 5: Missing /Kids Array

**Location:** `document.rs:806-810`
**Error Type:** `DocumentError::EmptyDocument`
**Detection Code:**
```rust
if kids_ref.is_none() {
    return Err(DocumentError::EmptyDocument { source });
}
```

**Scenario:** The Pages dictionary exists but has no `/Kids` entry, which is required for all /Pages nodes.

**Example PDF Structure:**
```pdf
2 0 obj
<<
/Type /Pages
% No /Kids entry - this is a structural error
/Count 0
>>
endobj
```

**Behavior:** Per PDF spec 1.7 section 7.7.3.2, every /Pages node must have a `/Kids` array. Missing `/Kids` indicates a malformed page tree.

## Variant 8: Zero Page Count from Tree Traversal

**Location:** `document.rs:855-861`
**Error Type:** `DocumentError::EmptyDocument`
**Detection Code:**
```rust
match count_pages_tree(resolver, catalog.pages_ref) {
    Ok(page_count) => {
        if page_count == 0 {
            return Err(DocumentError::EmptyDocument { source });
        }
        // ...
    }
    // ...
}
```

**Scenario:** The page tree structure exists but traversal yields zero leaf /Page nodes.

**Example PDF Structures:**

**All /Pages Nodes (No Leaves):**
```pdf
2 0 obj
<<
/Type /Pages
/Kids [3 0 R]    % Reference to another /Pages
>>
endobj
3 0 obj
<<
/Type /Pages
/Kids []         % Empty leaf - no actual /Page objects
>>
endobj
```

**Circular References Pruned:**
```pdf
2 0 obj
<<
/Type /Pages
/Kids [2 0 R]    % Self-reference creates cycle
>>
endobj
```

**Behavior:** `count_pages_tree()` walks the tree and counts only leaf `/Page` nodes. Structural issues (cycles, depth exceeded) prune subtrees and may result in zero pages.

## Variant 9: Page Tree Traversal Failure

**Location:** `document.rs:875-881`
**Error Type:** `DocumentError::EmptyDocument`
**Detection Code:**
```rust
Err(_) => {
    return Err(DocumentError::EmptyDocument { source });
}
```

**Scenario:** Page tree traversal fails completely due to structural corruption.

**Example Failure Modes:**

**Circular References:**
```pdf
2 0 obj
<<
/Type /Pages
/Kids [3 0 R]
>>
endobj
3 0 obj
<<
/Type /Pages
/Kids [2 0 R]    % Cycle back to 2
>>
endobj
```

**Depth Exceeded (>16 levels):**
```pdf
% Each /Pages references the next, exceeding MAX_PAGES_DEPTH
```

**Corrupted xref entries:**
```
% xref table has invalid or missing entries for page tree nodes
```

**Behavior:** `count_pages_tree()` returns `Err(diagnostics)` when it can't complete traversal. This is treated as an empty document.

## Variant 10: Invalid /Pages Type in Catalog

**Location:** `catalog.rs:501-514`
**Error Type:** Emits `STRUCT_MISSING_KEY` diagnostic; returns default Catalog with `pages_ref = 0`
**Detection Code:**
```rust
let pages_ref = match catalog_dict.get("Pages") {
    Some(PdfObject::Ref(ref_)) => *ref_,
    Some(other) => {
        diagnostics.push(Diagnostic::with_dynamic_no_offset(
            DiagCode::StructMissingKey,
            format!("STRUCT_MISSING_KEY: /Pages is not a reference (type: {})", other.type_name()),
        ));
        catalog.diagnostics = diagnostics;
        return Ok(catalog);  // Returns catalog with pages_ref = 0
    }
    None => {
        diagnostics.push(Diagnostic::with_dynamic_no_offset(
            DiagCode::StructMissingKey,
            "STRUCT_MISSING_KEY: /Pages key missing from catalog".to_string(),
        ));
        catalog.diagnostics = diagnostics;
        return Ok(catalog);  // Returns catalog with pages_ref = 0
    }
};
```

**Scenario:** The catalog has a `/Pages` entry but it's not an indirect reference.

**Example PDF Structures:**

**Direct Dictionary (Invalid):**
```pdf
1 0 obj
<<
/Type /Catalog
/Pages <<            % /Pages must be a reference, not a direct dict
  /Type /Pages
  /Kids [3 0 R]
  /Count 1
>>
>>
endobj
```

**Null /Pages:**
```pdf
1 0 obj
<<
/Type /Catalog
/Pages null          % /Pages is explicitly null
>>
endobj
```

**Integer /Pages:**
```pdf
1 0 obj
<<
/Type /Catalog
/Pages 42            % /Pages is a direct integer (invalid)
>>
endobj
```

**Behavior:** Catalog parsing succeeds but emits `STRUCT_MISSING_KEY` and returns a default Catalog. The invalid pages_ref (0) triggers `MissingPagesArray` error during `validate_pages_structure()`.

## Edge Cases and Special Scenarios

### EC-01: Empty PDF (from plan)
A 0-byte file or a syntactically valid PDF with zero pages.

- **0-byte file:** Fails during `find_startxref()` or PDF header validation
- **Syntactically valid with zero pages:** Caught by Variant 6 (Empty /Kids array) or Variant 8 (Zero page count)

### Circular References
Detected via `visited` HashSet in `count_pages_walk()` (pages.rs:169-198):
- First occurrence: normal traversal
- Subsequent visits: emit `STRUCT_CIRCULAR_REF`, return 0 (subtree pruned)

### Depth Limiting
Maximum nesting depth: 16 levels (`MAX_PAGES_DEPTH` constant)
- Exceeding depth: emit `STRUCT_DEPTH_EXCEEDED`, prune subtree, may result in zero pages

### Inherited Attributes
Empty documents may still have valid inheritable attributes on intermediate /Pages nodes:
- `/MediaBox`, `/CropBox`, `/Resources`, `/Rotate` on /Pages nodes
- These are accumulated during `flatten_page_tree()` but never used if no leaf pages exist
