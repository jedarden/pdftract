## Notes
The task description mentioned `[GenerateSerializer]`, but in MessagePack 3.x, the correct attribute for source generation is `[MessagePackObject]`. The `MessagePackAnalyzer` package (referenced in the project) provides the source generation capability.

All records use `init` properties for immutability and `required` keyword for non-nullable reference properties, following C# best practices.
