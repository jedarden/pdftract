## Algorithm Implementation Details

The implementation follows the classic Bresenham line algorithm:

1. **Initialize:**
   - `dx = |x1 - x0|`, `dy = |y1 - y0|` (absolute distances)
   - `sx = ±1`, `sy = ±1` (step directions)
   - `err = dx - dy` (initial error term)

2. **Main loop:**
   - Plot current pixel if in bounds
   - Terminate if endpoint reached
   - Update error term: `e2 = 2 * err`
   - Step in x if `e2 > -dy`
   - Step in y if `e2 < dx`

3. **Pixel plotting:**
   - Bounds-checked: `0 ≤ x < 32`, `0 ≤ y < 32`
   - Color: 0 (black/stroke color)
