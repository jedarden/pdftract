## Summary

Implemented the error handling system in `codegen/errors.go` with the 8 required error kinds, `PdftractError` struct, and full `errors.Is/As` compatibility.

- `pdftract-go/codegen/errors.go` - Error type definitions and helper functions

## Implementation Details

### ErrKind Enum (8 error kinds)

All 8 error kinds are defined as constants with values 1-8:

1. `ErrCorruptPDF` (1) - Corrupt or malformed PDF (exit code 2)
2. `ErrEncryption` (2) - Encrypted PDF requiring password (exit code 3)
3. `ErrIO` (3) - I/O error (exit code 4)
4. `ErrInvalidSource` (4) - Invalid or inaccessible source (exit code 5)
5. `ErrOCRFailed` (5) - OCR processing failed (exit code 6)
6. `ErrOutOfMemory` (6) - Out of memory error (exit code 7)
7. `ErrPagination` (7) - Pagination error (exit code 8)
8. `ErrUnknown` (8) - Unknown error (default)

### PdftractError Struct

```go
type PdftractError struct {
    Kind     ErrKind
    Message  string
    ExitCode int
}
```

Implements:
- `Error() string` - Returns descriptive error message with kind and exit code
- `Is(target error) bool` - Enables `errors.Is` matching by kind

### Predefined Error Instances

Eight predefined error instances for use with `errors.Is`:
- `ErrCorruptPDFInstance`
- `ErrEncryptionInstance`
- `ErrIOInstance`
- `ErrInvalidSourceInstance`
- `ErrOCRFailedInstance`
- `ErrOutOfMemoryInstance`
- `ErrPaginationInstance`
- `ErrUnknownInstance`

### Helper Functions

- `NewPdftractError(exitCode int, message string)` - Creates error from exit code
- `mapExitCodeToErrKind(exitCode int)` - Maps exit codes to ErrKind
- `AsPdftractError(err error)` - Convenience wrapper for `errors.As`

## Example Usage

```go
// Create error from exit code
err := NewPdftractError(2, "file header is invalid")

// Check specific error kind
if errors.Is(err, ErrCorruptPDFInstance) {
    // Handle corrupt PDF case
}

// Extract error details
if pdftractErr, ok := AsPdftractError(err); ok {
    fmt.Printf("Kind: %v, Message: %s, ExitCode: %d\n",
        pdftractErr.Kind, pdftractErr.Message, pdftractErr.ExitCode)
}
```
