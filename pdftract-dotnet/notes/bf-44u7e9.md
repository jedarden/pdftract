## Note on `[GenerateSerializer]` vs `[MessagePackObject]`

The bead description requested `[GenerateSerializer]` for MessagePack source generation. This attribute does not exist in MessagePack 3.x. The correct attribute for MessagePack serialization is `[MessagePackObject]` with `[Key]` attributes on each property, which enables source generation through the MessagePackAnalyzer package.
